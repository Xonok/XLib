# xconf

A JSON configuration loader with layered defaults, overrides, and omission
handling. It reads configuration from a directory structure, merges the layers
deeply, handles missing keys with configurable policies, and saves diffs back
to the user config file.

`SPEC.md` has the module map, the data flow, and the invariants.

## XLib rules

This library(xconf) is AI-written and may be edited by AI.
Its spec and its tests are AI-written too, and may be edited as needed.
