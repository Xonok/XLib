# xtest

A lightweight test runner with assertion helpers. It provides a minimal set of
assertions, a `@test` decorator for registering tests, and a `run()` function
that discovers and executes test functions from a directory, a module, or the
global registry. Zero dependencies by design.

`SPEC.md` has the module map, the data flow, and the invariants.

## XLib rules

Its spec and its tests are AI-written too, and may be edited as needed.
