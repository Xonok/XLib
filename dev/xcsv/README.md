# xcsv

A CSV library with `//` comment support, quoting, and a simple
tokenizer/serializer. Header-ignoring is the default; header-aware reads and
writes are a layer on top of it.

`SPEC.md` has the module map, the data flow, and the invariants.

## XLib rules

This library(xcsv) is AI-written and may be edited by AI.
Its spec and its tests are AI-written too, and may be edited as needed.
