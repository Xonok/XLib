# xschema

A runtime type and schema system that validates Python values against type
specifications. One `parse()` funnel accepts two equivalent expression forms,
and a `Schema` built from a function signature validates every call.

`SPEC.md` has the module map, the data flow, and the invariants.

## XLib rules

This library(xschema) is AI-written and may be edited by AI.
Its spec and its tests are AI-written too, and may be edited as needed.
